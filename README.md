# Centre for Sustainable Technologies (CST) | IISc Bangalore
### Departmental Research Portal & Academic Showcase

An institutional web application for the **Centre for Sustainable Technologies (CST)** / *Centre for Sustainable Development* at the **Indian Institute of Science (IISc), Bangalore**.

---

## 🏛️ About the Portal

Established in 1974 as ASTRA (Application of Science and Technology to Rural Areas) under the leadership of Prof. Amulya K. N. Reddy, CST pioneers multidisciplinary research across clean energy, circular bioeconomy, low-carbon building materials, and ecological sanitation.

This portal provides an interactive showcase of CST's research initiatives, peer-reviewed publications, faculty leadership, pilot plant infrastructure, and academic programs.

---

## ✨ Features

- **Departmental Home Hub**: 12 dedicated sections including Chair's Editorial Message (Prof. S. Dasappa), Strategic Research Pillars, Advanced Pilot Facilities, and Sponsoring R&D Ecosystem.
- **Real-Time Announcement Ticker**: Live moving announcements ticker with modal readouts for symposia, fellowships, and defense notices.
- **Deep Research Archive**: 48+ categorized research projects spanning 1974–2026 with full-text search and theme filtering.
- **Peer-Reviewed Publications**: Searchable publications archive with journal badges, year filters, and DOI links.
- **Faculty & Scholars Directory**: Research profiles, citations, lab affiliations, and direct scholar listings.
- **Campus Access & Direct Inquiry**: Transit directions from Kempegowda International Airport and railway terminals, plus an automated academic inquiry dispatch system connected to `navyabhat111@gmail.com`.
- **Administrative Portal**: Secure department management console (`admin@iisc.ac.in`) with entry addition and deletion capabilities.
- **Design & Performance**: Academic light theme with terracotta, forest green, and IISc navy accents. Fully responsive and mobile-friendly.

## 🛠️ Tech Stack

- **Framework**: React 19
- **Bundler & Dev Server**: Vite
- **Icons**: Lucide React
- **Styling**: Vanilla CSS (Custom tokens, glassmorphism, responsive grid)
- **Deployment**: Single Page Application with Hash Routing

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/Adi0418/research.git

# Navigate to project directory
cd research

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
